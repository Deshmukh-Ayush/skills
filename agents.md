# Agents

This repository contains skills designed to guide AI assistants in providing design and product decisions.

## Family Design Values
- Skill: `skills/family-values/SKILL.md`
- Purpose: A decision framework for UI design quality based on the Family wallet team's principles of simplicity, fluidity, and delight.
- Usage: Use this skill when making interface architecture, motion decisions, or reviewing whether a UI feels polished and coherent.
